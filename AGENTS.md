# Agent guidance — superconductor/core

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing a message, a procedure, the client or the server. Open only the concepts the change touches.
2. **The spec versions are 2025-06-18, 2025-03-26 and 2024-11-05, and the protocol line is accumulated, never dropped.** A new version is a new stop (`2025-11-25`, `2026-07-28`); the ones before it keep working. Behaviour that differs by version reads the negotiated version on the bag. Batches are received through `LineDecoder::decode()` below 2025-06-18, refused from it, and never sent. Check the spec page for the version before changing a wire shape. See [`.okf/protocol/messages.md`](.okf/protocol/messages.md).
3. **Session logic lives here, in `Mechanism\Session`**, not in a transport. A transport feeds `Session::handle()` and sends what the closure gives it. See [`.okf/mechanism/session.md`](.okf/mechanism/session.md).
4. **Server and client are different entities.** A server is a sketch run by a transport; an `MCPServer` only says what it serves. A client is an in-process component inside the application's own loop, one `MCPClient` per connection, and never owns a loop. They share only messages, definitions and the router. Both extend `Mechanism\MCPEntity`. See [`.okf/architecture/roles.md`](.okf/architecture/roles.md).
5. **Outside code types against the contracts.** A parameter, return type or container id that names a server or a client names `Contracts\Server\MCPServer` or `Contracts\Client\MCPClient`; `extends` and construction stay on the concrete classes. A method that code outside the class calls is declared on the contract. See [`.okf/architecture/roles.md`](.okf/architecture/roles.md).
6. **Every wire shape is a readonly message class.** Requests are built from a decoded line by `generate()` and sent with `toJson()`; responses are built from a reply by `fromReceived()` and sent with `toJson()`. Empty maps go out as `{}`. The decoder is the only place a line is trusted. See [`.okf/protocol/messages.md`](.okf/protocol/messages.md).
7. **Errors are JSON-RPC errors with the spec's code and the request's id.** Reuse `InvalidRequest`, `InvalidParams`, `MethodNotFound`, `InternalError` and the MCP-coded ones; never add an error class for a message that an existing one plus text can carry. A notification is never answered. See [`.okf/protocol/errors.md`](.okf/protocol/errors.md).
8. **Ids are per requestor.** Each side keeps two `RequestIds`: one for the ids it sent, one for the ids it received. A repeated incoming id is refused; the two sides may use the same numbers. See [`.okf/protocol/ids.md`](.okf/protocol/ids.md).
9. **Capabilities gate what goes out.** `MCPServer::notify()` drops a notification the server does not advertise; `MCPServerBag::wants()` drops what this session did not ask for; the client lists only what the server advertised. See [`.okf/server/capabilities.md`](.okf/server/capabilities.md).
10. **Procedures that run developer code are `ASYNC`.** Tool calls, resource reads, prompt gets and completion run in a loop fiber so pings, cancellation and progress work while they run. Lifecycle and list procedures stay synchronous. See [`.okf/mechanism/procedures.md`](.okf/mechanism/procedures.md).
11. **Config keys are documented and mirrored.** A key added to `config/mcp.php` is described in the README and copied into any app that published the file. No key is read that the file does not declare.
12. **Transports are separate packages** (`superconductor/stdio`; `superconductor/web` is planned). This package knows no transport by name; a transport registers its sketch through `sketches.load` and its client creator on `mcp.clients`. See [`.okf/architecture/transports.md`](.okf/architecture/transports.md).
13. **Tests are Pest v4 and need no server.** The client is tested on a `FakeConnection`, procedures on a bench `MCPServer`, the decoder on lines. `venusian/framework` is in `require-dev` because the code calls `config()` and `app()`. A behaviour change comes with a test; `vendor/bin/pest` stays green.
14. **Durable facts go in `.okf`.** Update the matching concept, bump its `generated.at`, append `.okf/log.md`. The bundle documents the package, never a session.
15. **Versions** move only past a published tag: `composer.json` `version`, the split manifests and `MCPClient::VERSION` move together (now 0.11.0).
